# דף מקורות

כלי web-based לבניית "דפי מקורות" — אסופות מאורגנות של מקורות יהודיים — עם אינטגרציה ישירה למאגר [ספריא](https://www.sefaria.org).
המערכת מיועדת למורי שיעורי שבת ולמחנכים בחינוך תורני שמכינים דפי שיעור להדפסה.

## ✨ מה היא יודעת לעשות

- חיפוש מקור בעברית ב-API של ספריא
- שליפת טקסט מנוקד (ללא טעמים) להצגה
- בנייה הדרגתית של דף מקורות עם מראה מקום אוטומטי
- הוספת מקורות עצמאיים (טקסט חופשי / הערות)
- עריכה, מחיקה וסידור מקורות
- שמירה אוטומטית של טיוטה ב-`localStorage`
- ספרייה של דפים שמורים
- ייצוא ל-PDF דרך הדפסת הדפדפן עם CSS print ייעודי

## 🚀 הרצה מקומית

הפרויקט הוא static HTML/CSS/JS — אין צורך ב-build:

```bash
# פתיחה מקומית (כל שרת סטטי יספיק)
python3 -m http.server 8000
# ואז: http://localhost:8000
```

או פשוט הרץ את הקובץ `index.html` בדפדפן (קריאות API של ספריא דורשות חיבור רשת).

## 🌐 פריסה ב-GitHub Pages

1. ב-Repository Settings → Pages
2. בחר את ה-branch `main` (תיקייה `/`)
3. הדף יופיע בכתובת `https://<user>.github.io/<repo>/`

## 🗂 מבנה

```
/
├── index.html
├── css/
│   ├── main.css      — layout ועיצוב כללי
│   ├── rtl.css       — התאמות RTL
│   ├── print.css     — @media print לייצוא PDF
│   └── fonts.css     — פונטים עבריים
├── js/
│   ├── app.js        — אתחול וניהול ראשי
│   ├── sefaria-api.js — client ל-API של ספריא
│   ├── sources.js    — CRUD על המקורות בדף
│   ├── storage.js    — localStorage layer
│   ├── ui-sheet.js   — ממשק דף המקורות
│   ├── ui-browser.js — ממשק דפדפן ספריא
│   ├── export.js     — הדפסה / PDF
│   └── utils.js      — עזרי טקסט עברי
└── CLAUDE.md         — מפרט הפיתוח המלא
```

ראה `CLAUDE.md` למפרט המלא, ל-phased plan ולקווים מנחים לפיתוח.
