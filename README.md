# דף מקורות

כלי web סטטי לבניית **דפי מקורות** לשיעורי תורה — חיפוש בספריא, בנייה אינטראקטיבית של הדף, הדפסה לפורמט PDF נקי. מאוכלס ב-[GitHub Pages](https://nadaval56.github.io/daf-mekorot/).

מיועד למורי שיעורי שבת ולמחנכים בחינוך תורני שמכינים דפי שיעור להדפסה.

## ✨ מה הכלי יודע

- **חיפוש** מקור בעברית ב-API של ספריא + autocomplete.
- **עץ ניווט** מבוסס על TOC של ספריא: תנ"ך → תורה/נביאים/כתובים → ספר → פרק → פסוק. תלמוד בבלי → מסכת → דף → עמוד. וכן הלאה לכל הקטגוריות (משנה, מדרש, הלכה, קבלה, חסידות, מוסר, מחשבת ישראל, ליטורגיה, …).
- **שורת chips** מעל אזור התוצאות לקפיצה ישירה לקטגוריה.
- **מקורות מקושרים** מתחת לכל פסוק/שורה: פרשנים מקובצים לפי שם פרשן, תרגומים, מדרשים, סוגיות, וכו'. הרחבה inline, "פתח כמקור הראשי" לדריל אל הפרשן.
- **כינוי שמות ה'** אוטומטי (יהוה → י-הוה וכו') — מופעל כברירת מחדל, עם הבחנה בין צירי (אֵל = שם ה') לסגול (אֶל = מילת יחס).
- **דף המקורות**: כותרת, "בס"ד" קובייה נשלפת, שדה תאריך/כותרת משנה, רשימת מקורות עם:
  - מראה מקום עברי אוטומטי (פורמט לפי קטגוריה — ראה `CLAUDE.md` סעיף 5).
  - עריכה inline של כותרת וטקסט.
  - גרירה (drag handle `⋮⋮`) או חיצי ⬆⬇ לסידור.
  - מחיקה במחיקה אחת בלי `confirm()`.
- **שמירה**: auto-save של טיוטה ב-`localStorage`, ספרייה של דפים שמורים, שכפול, מחיקה.
- **הגדרות עיצוב**: פונט (Frank Ruhl Libre / David / Bellefair / Heebo), גודל גופן, מספור, קו מפריד, מספרי עמודים, שולי דף.
- **ייצוא PDF**: `window.print()` עם `@media print` ייעודי — בס"ד למעלה, כותרת, מקורות גולשים טבעית בין עמודים.

## 🚀 הרצה מקומית

הפרויקט סטטי — אין build:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

או פתח את `index.html` ישירות בדפדפן (קריאות ל-Sefaria API דורשות חיבור).

## 🌐 פריסה

`main` נדחף ל-GitHub Pages אוטומטית (Settings → Pages → branch `main`, תיקייה `/`).

## 🗂 מבנה

```
/
├── index.html                 # שלד ה-DOM
├── css/
│   ├── main.css              # layout + עיצוב מסך
│   ├── rtl.css               # התאמות RTL
│   ├── print.css             # @media print
│   └── fonts.css             # פונטים עבריים
├── js/
│   ├── app.js                # אתחול + wiring + modals
│   ├── sefaria-api.js        # לקוח Sefaria + cache + complex-schema fallback
│   ├── sources.js            # מודל Sheet (CRUD), observable
│   ├── storage.js            # localStorage layer
│   ├── ui-sheet.js           # פאנל ימני (דף המקורות)
│   ├── ui-browser.js         # פאנל שמאלי (ספריא)
│   ├── export.js             # print / PDF / JSON
│   └── utils.js              # text helpers + Hashem kinnui
├── assets/favicon.svg
├── CLAUDE.md                 # מדריך פיתוח (קרא לפני שינוי קוד)
└── README.md
```
